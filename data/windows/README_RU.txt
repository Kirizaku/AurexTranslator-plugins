Aurex Translator Plugins (Windows)

----------------------
Структура:
----------------------
plugins/
  libat-injector.dll                - Библиотека-обертка (нужна всем hook-плагинам)
  bin/at-injector_x64.exe, _x86.exe - Утилита внедрения (64/32-bit)

  Hook-плагины (перехват текста игр):
  libat-imhhw.dll                   - If My Heart Had Wings
  libat-renpy_x64.dll, _x86.dll     - Игры на движке Ren'Py
  libat-kirikiri_x86.dll            - Игры на движке KiriKiri / KiriKiriZ
  libat-unity_x64.dll, _x86.dll     - Игры на Unity (Mono и IL2CPP)

  Оверлей в игре (показывает перевод в играх на D3D9-12, OpenGL и Vulkan,
  захватывает изображение для OCR):
  libat-overlay_x64.dll, _x86.dll

----------------------
Установка:
----------------------
1. Скопируйте все файлы в папку plugins (подпапку bin\ сохраните):
   %LOCALAPPDATA%\AurexTranslator\plugins\

----------------------
Использование:
----------------------
Hook:
1. Запустите игру
2. В Aurex Translator перейдите: Обработка текста -> HOOK
3. Выберите игру или движок из списка
Текст будет перехватываться и переводиться автоматически.
Для каждой игры/движка нужен отдельный плагин.

Оверлей:
1. Только для игр на Vulkan: в Aurex Translator перейдите Вывод -> вкладка «Оверлей в игре» -> «Слой Vulkan» -> «Установить».
   Это нужно сделать ДО запуска игры (программа также предлагает это сама).
2. Вывод -> отметьте «Текстовый оверлей в игре»
   (по желанию: чтобы брать изображение игры для OCR из самой игры, выберите еще и режим захвата «Оверлей»;
   его можно сочетать с текстовым оверлеем)
3. Запустите игру
4. Нажмите «Выбрать игру...» -> «Добавить игру...» и выберите запущенную игру

Готовые конфиги для игр на KiriKiri — см. отдельный файл "kirikiri-configs" в этом релизе.

Лицензии: см. папку licenses\ (сторонние уведомления включены).
