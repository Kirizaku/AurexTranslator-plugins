KiriKiri Engine Configs

----------------------
KiriKiri.json contains pre-configured hook settings for the following games:
  - Atri: My Dear Moments (Linux)
  - Tricolour Lovestory (Windows/Linux)
  - The House in Fata Morgana: A Requiem for Innocence (Windows/Linux)

----------------------
Requirements:
----------------------
The "KiriKiri" engine plugin must already be installed in your plugins folder
— see the main plugins asset in this release for that.

----------------------
Installation:
----------------------
1. Copy KiriKiri.json to your plugins configs folder:
   Linux:   ~/.config/AurexTranslator/plugins/configs/
   Windows: %LOCALAPPDATA%\AurexTranslator\plugins\configs\
2. In Aurex Translator, open the Configs tab and load KiriKiri

----------------------
Usage:
----------------------
1. Launch one of the supported games
2. In Aurex Translator go to:
   Text Processing -> HOOK -> Engine (KiriKiri) -> select the running game process
   Text will be automatically captured and translated using the pre-configured settings.
