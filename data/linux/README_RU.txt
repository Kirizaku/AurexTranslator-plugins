Aurex Translator Plugins (Linux)

----------------------
Структура:
----------------------
plugins/
  libat-injector.so            - Библиотека-обертка (нужна всем hook-плагинам)
  bin/at-injector_x64, _x86    - Утилита внедрения (64/32-bit)

  Hook-плагины (перехват текста игр):
  libat-imhhw.so               - If My Heart Had Wings
  libat-renpy_x64.so, _x86.so  - Игры на движке Ren'Py
  libat-kirikiri_x86.so        - Игры на движке KiriKiri / KiriKiriZ
  libat-unity_x64.so, _x86.so  - Игры на Unity (Mono и IL2CPP)

  Оверлей в игре (показывает перевод, захватывает изображение для OCR):
  libat-overlay-vulkan_x64.so, _x86.so    - Игры на Vulkan
  libat-overlay-opengl_x64.so, _x86.so    - Игры на OpenGL
  libat-overlay-shim_x64.so, _x86.so      - Лаунчер: включает оверлей в играх, запущенных через него

----------------------
Установка:
----------------------
1. Скопируйте все файлы в папку plugins (подпапку bin/ сохраните):
   ~/.config/AurexTranslator/plugins/
2. (Опционально) Выдайте права, чтобы не вводить пароль.
   Aurex Translator предлагает это сам в настройках HOOK; вручную:
   sudo setcap cap_sys_ptrace+ep ~/.config/AurexTranslator/plugins/bin/at-injector_x64
   sudo setcap cap_sys_ptrace+ep ~/.config/AurexTranslator/plugins/bin/at-injector_x86

----------------------
Использование:
----------------------
Hook:
1. Запустите игру
2. В Aurex Translator перейдите: Обработка текста -> HOOK
3. Выберите игру или движок из списка
Текст будет перехватываться и переводиться автоматически.
Для каждой игры/движка нужен отдельный плагин.

Оверлей:
1. В Aurex Translator перейдите: Вывод -> вкладка «Оверлей в игре» -> «Запуск Vulkan/OpenGL» -> «Установить»
   (ставится слой Vulkan и скрипт запуска; программа предлагает это и сама)
2. Вывод -> отметьте «Текстовый оверлей в игре»
   (по желанию: чтобы брать изображение игры для OCR из самой игры, выберите еще и режим захвата «Оверлей»;
   его можно сочетать с текстовым оверлеем)
3. Запустите игру ЧЕРЕЗ скрипт запуска (программа показывает команду)
4. Нажмите «Выбрать игру...» и выберите игру

Готовые конфиги для игр на KiriKiri — см. отдельный файл "kirikiri-configs" в этом релизе.

Лицензии: см. папку licenses/ (сторонние уведомления включены).
